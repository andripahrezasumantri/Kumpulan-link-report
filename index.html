Panduan Penggunaan All In One Link Report

Sistem Manajemen Report Terpusat untuk Unit MDS 311 Banjarmasin.

MDS 311 Banjarmasin

1. Aturan Auto-Archive (10 Hari)

Setiap report yang diubah statusnya menjadi **Selesai** akan tetap tersimpan di tab Selesai selama **10 hari** sebagai bukti rekam jejak pekerjaan harian/mingguan. Setelah melewati 10 hari, report secara otomatis diarsipkan agar layar utama selalu bersih.

2. Centang Cepat (1-Click Finish)

Selesaikan report tanpa membuka form edit! Cukup klik **lingkaran centang** di sebelah kiri judul report pada tabel. Status akan berubah seketika menjadi **✓ Selesai**, judul dicoret, dan angka pada stat cards diperbarui otomatis.

3. Pencarian Instan (<10 Detik)

Temukan link report yang tersebar di WA, Email, atau Teams dalam hitungan detik. Gunakan kolom pencarian di navbar atas atau saring berdasarkan kategori (Finance, Operasional, HR, dll.) serta asal sumber link.

4. Dashboard Statistik Visual

Menu **Dashboard** menyajikan ringkasan statistik angka dan grafik *doughnut/bar chart* interaktif tanpa menampilkan tabel data, memudahkan jajaran manajemen memantau progres pekerjaan toko secara cepat.
